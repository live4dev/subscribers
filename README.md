# Telegram Subscribers Bot

Бот для отслеживания подписчиков Telegram-каналов. Автоматически фиксирует новых подписчиков и отписки, поддерживает несколько каналов одновременно.

## Возможности

- Уведомления о новых подписчиках и отписках в реальном времени
- Различает новых подписчиков и вернувшихся
- Хранит историю: дату первой подписки для каждого пользователя
- Поддерживает несколько каналов без дополнительной настройки
- Команда для первичного импорта существующих подписчиков через Telethon

## Структура проекта


## Быстрый старт

### 1. Настройка окружения

```bash
cp .env.example .env
```

Заполнить `.env`:

```env
BOT_TOKEN=токен_от_BotFather
NOTIFICATION_CHAT_ID=ваш_chat_id
```

- `BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather)
- `NOTIFICATION_CHAT_ID` — ID чата для уведомлений, узнать у [@userinfobot](https://t.me/userinfobot)

### 2. Добавить бота в канал

В настройках канала → **Администраторы** → добавить бота с правом **«Управление каналом»** (manage_chat).

> Без этого права Telegram не отправляет боту события о подписках.

### 3. Запуск

**Локально:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

**Через Docker:**

```bash
docker compose up -d
docker compose logs -f   # просмотр логов
docker compose down      # остановка
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/help` | Список доступных команд |
| `/ping` | Проверить, что бот работает |
| `/channels` | Список каналов с владельцем и ссылкой |
| `/stats` | Статистика подписчиков по каналам |

## Хранилище данных

Для каждого канала создаётся файл `data/{channel_id}.txt`:

```
# user_id|first_seen|status
123456789|2024-01-15 10:30:00|active
987654321|2024-01-16 11:00:00|inactive
```

| Поле | Описание |
|------|----------|
| `user_id` | Telegram ID пользователя |
| `first_seen` | Дата первой подписки |
| `status` | `active` — подписан, `inactive` — отписался |

Файл для нового канала создаётся автоматически при первом событии.

## Импорт существующих подписчиков

Бот отслеживает только события с момента запуска. Чтобы загрузить текущих подписчиков, используется скрипт на базе [Telethon](https://docs.telethon.dev) (MTProto API от имени пользователя).

### Настройка

1. Получить `API_ID` и `API_HASH` на [my.telegram.org](https://my.telegram.org) → API development tools
2. Добавить в `.env`:

```env
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890
```

### Запуск

```bash
python export_subscribers.py @mychannel
# или по Bot API ID:
python export_subscribers.py -1001234567890
```

При первом запуске потребуется авторизация по номеру телефона — сессия сохраняется в `subscriber_export.session` и повторно не запрашивается.

Скрипт не перезаписывает существующие записи: если пользователь уже есть в базе, его `first_seen` сохраняется.

## Добавление нового канала

Дополнительная настройка не нужна — достаточно добавить бота администратором в канал. Файл `data/{channel_id}.txt` создастся автоматически при первой подписке или отписке.

## Ограничения

- Bot API не позволяет получить список текущих подписчиков — используйте `export_subscribers.py` для первичного наполнения базы
- Для каналов с очень большим числом подписчиков (100k+) Telegram может ограничить результаты `iter_participants`
